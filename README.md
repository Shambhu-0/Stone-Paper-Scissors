# 🪨 Stone Paper Scissors

A simple command-line implementation of the classic Stone Paper Scissors game, built using **Python and Object-Oriented Programming (OOP)**.

## 🎮 About the Project

This project allows a player to play Stone Paper Scissors against the computer. The computer randomly selects its move, and the winner is determined according to the classic game rules.

The project was built as a Python practice project to improve my understanding of OOP, conditional statements, loops, dictionaries, and input handling.

## ✨ Features

- Play against a computer that randomly selects its move.
- Interactive command-line interface.
- Input validation to handle invalid choices.
- Automatic winner detection.
- Score tracking:
  - 10 points for every win.
  - Tracks total games played, won, lost, and tied.
- Option to replay the game.
- Final scorecard displayed when the player exits.

## 🛠️ Technologies Used

- Python 3
- Object-Oriented Programming
- Random module

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/Shambhu-0/stone-paper-scissors.git
   ```

2. Navigate to the project directory:

   ```bash
   cd stone-paper-scissors
   ```

3. Run the game:

   ```bash
   python3 stone_paper_scissors.py
   ```

## 📷 Game Preview

The game runs directly in the terminal and displays the player's choice, computer's choice, and the result of each round.
